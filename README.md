## Local Development

This site requires Jekyll. To run locally:

```bash
bundle install
bundle exec jekyll serve
```

Then open [http://localhost:4000](http://localhost:4000).

> **Note:** Do not use VS Code Live Server — it does not process Jekyll's Liquid templates.
